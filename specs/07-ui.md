# Spec 07 — Chat UI (React + Vite + TS)

Look: clean, calm, credible for a research-institution demo. Left rail: conversation
list + login-as switcher (alice, bob, asha, cora — sets the bearer token; switching
starts a fresh thread). Main: chat with SSE streaming.

Response renderings by response_type:
- answer: text with citation chips; clicking a chip shows the chunk text + breadcrumb.
- rows_answer: text plus a compact evidence table of the returned rows.
- approval_request: card with the payload preview (key-value), Approve and Decline
  buttons; after decision, the card locks and shows the outcome + action id.
- redirect: visually distinct (info style), showing the "not verified" statement and
  the pointed-to document or role.
- scope: friendly out-of-scope message.
- forbidden: the denial text, styled like redirect.

Also: file upload (goes to personal RAG as private; show an "only you can see this"
note); an Admin page visible to cora only — audit table (filter by status/kind),
latest eval report summary, link to Langfuse (or last console traces).

## Manual checklist (complete during M7)

- Stream renders progressively; refresh restores the conversation (checkpointer).
- Citation chip opens the correct chunk for at least two different answers.
- Approval card: approve executes and the follow-up message references the result;
  decline cancels politely; both appear in the admin audit table.
- Upload as alice, ask about it as alice (answered), as bob (redirect — no leak).
- Switcher: the same "show my bookings" question yields different, correct data per user.
- Admin page hidden from non-admin users (route guard + API guard).
